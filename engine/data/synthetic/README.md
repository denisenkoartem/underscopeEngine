# SYNTHETIC data

Generated by `underscope.data.generate_synthetic` (n=500, seed=7). Fake VINs and makes. Not real market data.

- `vehicles.jsonl`: outcomes drawn from the same placeholder model the engine uses (config/assumptions.yaml).
- `vehicles_misspecified.jsonl`: same vehicles, outcomes drawn from `perturbed(assumptions, seed=99)`, a world where every placeholder is off by up to 25% and market noise is 1.5x wider.
- `vehicles_stratified*.jsonl`: 200 vehicles per damage band (light <15%, mid 15-50%, heavy >=50% repair ratio), picked from a pool of 3000 (seed 8), with same-model and misspecified truth.
